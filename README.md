# hub-plugin-reminders

<img src="icon.png" width="256" alt="Напоминания">

Плагин страницы Agents Hub «Напоминания». Сессия, которая закончила ход и ждёт слова владельца без вопроса карточкой, не попадает
в «Ждут вас»: на её строке только мелкое «ответ?». Плагин собирает такие ожидания и карточки без ответа в одном виде.

- Вид `#/x/reminders` (меню ☰) и плитка «Ждут вашего слова» над поиском (слот `sidebar.tiles`, видна, пока есть ожидания).
- «Ждут слова текстом»: сессии с меткой сторожа (`attention` в снимке): с какого времени, что ждёт, хвост итога. Поле ответа как в чате сессии,
  «Напомнить», «Не жду» (снимает метку, сессии ничего не пишется), «Открыть сессию».
- Туда же попадает запись «жду слова владельца» (`hub waiting`, поле `waiting` в снимке), если в тексте есть владелец (`владел…`, `owner` или номер
  карточки `qN`), записи больше 10 минут и не старше двух недель, сессия свободна, и у неё нет ни открытой карточки, ни метки сторожа. Не попадают
  ожидания не владельца («Google: ответ на апелляцию Play…»), цепочки через других («… -> beta-lab -> «да» владельца»), дежурство («жду новых задач
  владельца»), записи с пометкой устаревшей и удалённые сессии. Правило - `isOwnerWait` в `web/rows.js`, проверено на живых текстах.
- «Карточки без ответа»: вопросы формой старше 30 минут и моложе суток. «Открыть карточку», «Напомнить».
- «Без ответа больше суток»: карточки, которые ядро уже не показывает (старше суток, до двух недель). У каждой «Переспросить»: после подтверждения
  сессия получает от владельца текст по образцу ядра (`ASK_EXPIRED`): задать вопрос заново формой с контекстом в самом вопросе, а если не нужен -
  ответить одним «—». Если ядро уже переспросило сама сессию (`revived`, PR #356), вместо кнопки - «ядро переспросило». Не показываются:
  отвеченные, удалённые сессии и сдавшие задачу, задачи в `replied`/`stopped`/`closed`/`archived`, вопрос, который сессия уже задала заново.
- «Напомнить» и «Переспросить» шлют сессии короткий текст от имени владельца (`action: true`: не ответ на карточку); повтор той же строке - не раньше
  чем через 15 минут (память браузера). «Напомнить всем» - с подтверждением «Напомнить N сессиям?»; устаревшие карточки в него не входят.

Источник устаревших карточек - свой процесс плагина (`main.py`, `"run"` в `hub-plugin.json`): ядро держит такую карточку в `asks` сессии, а в снимок
страницы `asks` не отдаёт. Процесс читает состояние ядра (`core.journal.load_state`, только чтение) и отдаёт странице на `127.0.0.1:<порт страницы + 14>`
`GET /asks` - id, сессия, вопрос, варианты, с какого времени, переспросило ли ядро; запросы принимаются только со страницы хаба (Origin). Остальное -
снимок страницы и действия `/api/send`, `/api/dismiss`. Нужен API плагинов 1.30 (`"hub": "^1.30"`). Процесс не запущен - блок «Без ответа больше суток»
пуст, а вид пишет, что нужно сделать.

Проверка: `node --test tests/` (страница) и `python3 -m unittest discover -s tests` (процесс). Подключение: запись в `extensions` настроек хаба,
`{"reminders": {"path": "<папка>", "web": "web/main.js", "run": ["python3", "main.py"], "hub": "^1.30"}}`, затем `hub restart web ext:reminders`
(для установки из каталога `run` берётся из `hub-plugin.json`).
